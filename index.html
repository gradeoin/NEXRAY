Local dev (2026 best practice)

Opening HTML files directly works, but modules (like three.js) prefer an HTTP server. Use one of these:

Option A: VS Code Live Server

  1. Install the “Live Server” extension
  2. Right‑click index.html → “Open with Live Server”

Option B: Node

# in the project folder
npx serve

Option C: Python

# in the project folder
python -m http.server 5173
