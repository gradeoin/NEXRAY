Recommended 2026 stack options

You can be successful with many stacks. These options show up in the Stage pages:

Static / frontend

  • Plain HTML/CSS/JS (this project)
  • Optional framework: React (or equivalent)
  • Build tool: Vite (when you switch to modules/components)

Backend

  • Node.js (Express/Fastify) for learning fundamentals
  • Serverless: Cloudflare Workers / Functions
  • Firebase (Auth + Firestore) for speed

Data

  • NoSQL: Firestore / Dynamo style
  • SQL: Postgres (Supabase/Neon/etc.)
  • Search: Algolia/Meilisearch style tools

The meta skill

Tools change. Fundamentals don’t. Learn: HTTP, DOM, security basics, performance, and product thinking. Then switch stacks whenever you want.

Copy‑paste checklists

Pre‑launch checklist

  • Mobile layout tested (small + large phones)
  • Keyboard nav works (Tab/Shift+Tab)
  • Meta title/description set per page
  • OpenGraph image set
  • 404 page strategy (Stage 7)
  • Performance: images optimized
  • Analytics installed (privacy‑aware)

Security baseline

  • No secrets in frontend code
  • Rate limit API endpoints
  • Validate all input server‑side
  • Use HTTPS only
  • Auth tokens stored safely (avoid localStorage for high‑risk)

SEO baseline

  • Unique H1 per page
  • Logical headings (H2/H3) used correctly
  • Alt text for meaningful images
  • Internal linking between stages
  • Clean URLs + sitemap (Stage 7)
  • Schema.org where useful (Stage 7)

Brand polish

  • Consistent spacing scale (8px grid)
  • Consistent radius & shadow tokens
  • One primary accent color (orange)
  • Buttons have hover/focus states
  • Readable line length (~65 characters)

Three.js + 3D assets (how to keep it light)

This project includes a decorative three.js scene. For real products, keep 3D optional:

  • Only animate when in view (IntersectionObserver)
  • Prefer simple geometry + 1–2 lights
  • Lower pixel ratio on mobile
  • Provide a “Reduce motion” mode

You’ll learn these techniques in Stage 2 (frontend) and Stage 5 (pro polish).

Icon & image editing

  • SVG icons are editable in any vector editor
  • Use modern formats (AVIF/WebP) for photos
  • Use Cloudinary for dynamic transformations
