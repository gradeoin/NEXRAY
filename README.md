# NEXRAY

[![CI](https://github.com/gradeoin/NEXRAY/actions/workflows/ci.yml/badge.svg)](https://github.com/gradeoin/NEXRAY/actions/workflows/ci.yml)

Free 7-stage web development guide — from zero to full-stack pro in 2026.

🌐 **Live site:** [nexray.in](https://nexray.in)

## Overview

Nexray is a free, structured learning platform for web development. It covers HTML, CSS, JavaScript, backend, DevOps, and Android app development across 7 progressive stages.

## Getting Started

```bash
node server.js
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

```
├── index.html          # Homepage
├── guide/              # 7-stage learning guide
├── blog/               # Blog articles
├── js/                 # Client-side scripts
├── css/                # Stylesheets
├── assets/             # Images and icons
├── components/         # UI components
├── server.js           # Local development server
├── sw.js               # Service worker (offline support)
└── manifest.json       # PWA manifest
```

## Requirements

- Node.js ≥ 18
