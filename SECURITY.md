# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| latest  | ✅        |

## Reporting a Vulnerability

If you discover a security vulnerability in Nexray, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email us at: **security@nexray.in**

Please include:
- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested remediation (optional)

You can expect an initial response within **72 hours**. We will keep you informed of progress and notify you when the issue is resolved.

We appreciate responsible disclosure and will credit reporters in the release notes (unless you prefer to remain anonymous).
